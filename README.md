# Eulerly Interactives

Free interactive linear algebra explorations from the Eulerly course *Applied Linear Algebra: The Math Behind AI and Beyond*.

Live site: https://mlnjsh.github.io/eulerly-interactives/

- `norm_explorer.html` (lesson 2.2): L2, L1 and L-infinity norms
- `linear_combinations.html` (lesson 2.3): linear combination dials
- `cosine_dial.html` (lesson 3.3): cosine similarity dial, from -1 (opposite) through 0 (unrelated) to +1 (alike)
- `projection_explorer.html` (lesson 3.4): projection of b onto a, the scalar and vector projection, and the orthogonal remainder

Each page is a single self-contained HTML file with no dependencies.
