Elimination stepper

Row by row, watch a system of equations turn into a staircase. Each step does one row operation and shows its arithmetic, entry by entry. Green rings mark the pivots, the amber row is the one that just changed, and at the end the page reads off the answer: one solution, infinitely many, or none.

Scale each pivot to 1 and clear the entries above it. Or press Next step to solve by back substitution.

What to try

  • Run the 6.3 system to the end. Without pivoting the first operation is R3 → R3 − 2·R1, and the answer is (5, 3, −2).
  • Switch on partial pivoting and run it again. The steps change (a swap appears) but the answer does not.
  • Run Rank 2: the last row becomes 0 = 0, so z is free. Now run Rank 2 with 17: the same left side, but the last row says 0 = 1.
  • Press Continue to RREF on the 7.3 example and compare with [[1, 0, −1 | −2], [0, 1, 2 | 3]].
  • Run the Tiny pivot demo with pivoting off (x comes out 0, which is wrong), then switch pivoting on (x = 1).
From Eulerly lessons 6.3 and 7.1 to 7.3, Gaussian elimination, row echelon form and rank. Three row operations (swap, scale, add a multiple of one row to another) never change the solutions of a system, so we can use them to reach a staircase that is easy to read. Rank is the number of pivots. Watch next: 3Blue1Brown, Essence of Linear Algebra, chapter 7 (Inverse matrices, column space and null space).
